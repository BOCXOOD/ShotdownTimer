Менеджер таймеров ПК (Shutdown Timer)

Консольное и графическое (WPF) приложение на языке C#, предназначенное для автоматизации управления питанием персонального компьютера и управления жизненным циклом пользовательских приложений.
📋 О проекте

Данный проект был разработан в рамках выполнения практических заданий. Он прошел эволюцию от простого консольного приложения до полноценного десктопного приложения с графическим интерфейсом (WPF).
✨ Основные возможности

    ⏱️ Таймер выключения ПК: Установка таймера выключения компьютера с указанием времени в минутах или секундах.

    ❌ Отмена таймера: Возможность отменить запланированное выключение.

    📊 Обратный отсчет: Визуализация оставшегося времени до выключения в реальном времени (формат ЧЧ:ММ:СС).

    🔊 Звуковое уведомление: За 10 секунд до выключения программа издает звуковой сигнал (3 раза).

    🚫 Закрытие приложений по таймеру: Возможность завершить работу любого процесса (например, notepad) по истечении заданного времени.

    🛑 Отмена закрытия приложений: Возможность отменить таймер закрытия приложения до его срабатывания.

🏗️ Архитектура и технологии

    Язык программирования: C# (.NET)

    Интерфейс: Windows Presentation Foundation (WPF)

    Взаимодействие с ОС: Использование системной утилиты shutdown.exe и класса System.Diagnostics.Process для управления процессами.

    Асинхронность: Использование async/await, Task и CancellationToken для работы таймеров без блокировки интерфейса.

    Стиль кода: Соблюдение Microsoft C# Naming Guidelines (PascalCase, camelCase, _ для приватных полей).

🚀 Как запустить

    Перейдите в раздел Releases (Релизы) на панели справа.

    Скачайте последний архив (ZIP) с программой.

    Распакуйте архив в любую папку.

    Запустите файл ShutdownTimerRework.exe (или имя вашего .exe).

    Внимание: Для работы программы не требуется установленная Visual Studio или среда .NET, так как сборка выполнена как Self-contained (автономная).
